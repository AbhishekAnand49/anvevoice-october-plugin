# AnveVoice — Voice AI for October CMS

Add a real-time AI voice agent to your October CMS website in minutes.

## Features

- Real-time AI voice conversations
- Works in 50+ languages including Hindi and other Indian languages
- 4 widget position options (bottom-right, bottom-left, top-right, top-left)
- Light and dark theme support
- Setup in under 5 minutes
- Built-in analytics
- No coding required

## Installation

1. Install the plugin from the October CMS Marketplace
2. Go to **Settings → AnveVoice Settings**
3. Paste your **Embed ID** from [app.anvevoice.app](https://app.anvevoice.app)
4. Choose your widget position and theme
5. Click **Save** — the voice widget appears on all pages

## Getting Your Embed ID

1. Sign up free at [app.anvevoice.app](https://app.anvevoice.app)
2. Create a new voice assistant
3. Copy the Embed ID from your dashboard

## Requirements

- October CMS 3.x or 4.x
- PHP 7.4+
- A free AnveVoice account
